    A test version, shared for trying out

    Full Compass is still being built and checked. It has not been recognised or approved by HMRC or Companies House. Please try it with the demonstration data, check anything it works out, and don't use it to send real returns, payroll submissions, VAT returns or company accounts yet.

    01 Shared by every app

    Built the careful way

    • One record for each client

      A company's, partnership's or sole trader's details are entered once, on the start page, and set up in the apps you tick. Figures flow on: the books into the accounts, the accounts into the tax computation, a sole trader's profits into their return.

    • Your data stays with you

      Everything is kept in a data file on your own computer. There is no account to create with us and nothing in the cloud.

    • Worked from the law

      Each calculation is built from UK legislation and HMRC's published guidance, with its source recorded, and checked by hand-worked examples and HMRC's own test cases where HMRC publishes them.

    • Kept up to date from the start page

      When a new version is out, the start page offers Update, or Update all. It backs up your data file first, and checks every download against a signed list.

    02 Get started

    Up and running in a few minutes

    1. Download the setup

      One file, for Windows 10 and 11.

    2. Tick the apps you want

      The start page always comes. Add more apps later from its Tools menu.

    3. Try the demonstration data

      Help > Load Demonstration Data fills an empty data file with made-up clients to look around.
