01 Help

Getting started

The short version: install, set up your account, load the demonstration data and look around. Each app also has its own help: press F1, or the ? button on any window.

Your first ten minutes

  1. Install the apps you want

    Click Download at the top of this page, then open the file it saves in your Downloads folder. If a blue "Windows protected your PC" box appears, click More info, then Run anyway. Click Yes when Windows asks, then follow the setup: Next, I understand, Install, Finish. Afterwards, type "Full Compass" in the Start menu to find the apps.

  2. Set up your account

    The first time the start page opens, it asks for your name, a username and a password. You become the suite's primary administrator, and it shows a recovery code: write it down and keep it away from the computer, as it is shown only once.

  3. Load the demonstration data

    In the start page, choose Help > Load Demonstration Data. It fills an empty data file with made-up clients to look around: nothing in it is real.

  4. Open an app on a client

    Choose a client on the start page's Clients tab. Its card shows what each app holds for the client, with a button to open the app straight on that client, already signed in.

  5. Set up your practice

    When you're ready for your own clients, enter the practice's details in Tools > Settings, add colleagues in Tools > Users, and add clients with the + beside Search Clients.

Remember: a test version

Full Compass has not been recognised or approved by HMRC or Companies House. Check anything it works out, and don't use it to file real returns or accounts yet.

Questions

Where is my data kept?

Only on your computer, in your own Windows user's folders. All the apps share one data file, in %APPDATA%\uk.fullcompass.suite; Pay keeps its payroll backups in %APPDATA%\uk.fullcompass.pay. To find them, type %APPDATA% into File Explorer's address bar and press Enter.

How do I back up?

In the start page, File > Backup Data File saves a copy of the shared data file, and File > Restore Data File brings one back. Pay can also back up a company's payroll by itself. You can also close the apps and copy the two folders above somewhere safe. The start page backs up the data file by itself before every update.

Windows says it "protected your PC".

That is Windows' SmartScreen, shown because the setup isn't yet signed with a publisher's certificate. Choose More info, then Run anyway. Updates installed by the start page don't show it.

How do I uninstall it?

In Windows, Settings > Apps > Installed apps: uninstall each "Full Compass" app. Uninstalling never deletes your data. To remove that as well, delete the two folders named under "Where is my data kept?" yourself. Pay's backups are payroll records, which employers must keep for three years after the tax year they relate to.
